#   Cognify

##  Problem Statement

Students spend a lot of thier time making notes while searching from large PDFs, textbooks etc.

Understanding and writing down a topic may take some time.

It is also a hefty task to go through all of the notes previously made and revise efficiently before exams.

--

##  Proposed Solution

Cognify is an AI Powered learning platfrom allowing students to upload their files and interact with it using natural language.

--

##  Target Users

- College Students
- School Students
- Exam Aspirants

##  Core Features

- Authentication
- PDF Upload
- AI ChatBot
- Source Citation
- Chat History

##  Future Features

- Flashcards
- Quiz Generator
- Study Planner
- Analytics
- Collaboration
- Leaderboard with Friends
